# Undo/Redo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** アイテム・カテゴリ・リンクテンプレートの編集系操作を、`Cmd/Ctrl+Z`で取り消し、`Shift+Cmd/Ctrl+Z`(または`Ctrl+Y`)でやり直せるようにする。

**Architecture:** `TodoService`の対象メソッドに`@undoable("操作名")`デコレータを付け、呼び出しの前後で`items`・`categories`・`link_templates`のスナップショット(と記録のアイテム名の対応表)を比べ、変わっていれば履歴(`UndoHistory`、Undo/Redoとも上限50件)へ積む。`undo()`/`redo()`は現在の状態を反対側へ退避してスナップショットを復元する。実行記録本体は巻き戻さない。画面側は`KeyboardController`がキーを受け、`main.py`が通知・選択の整理・再描画を行う。

**Tech Stack:** Python 3.13、NiceGUI、pytest(`uv run pytest`)、mypy strict(`uv run mypy src`)

**Spec:** `docs/superpowers/specs/2026-10-21-undo-redo-design.md`

## Global Constraints

- 画面の言語・通知文言は日本語。コメントも既存コードに合わせて日本語
- Python 3.13以上。型は`mypy --strict`を通す
- サービス層は`from __future__ import annotations`を使っている。既存のコードの密度・命名に合わせる(コメントは「なぜ」だけを簡潔に)
- 履歴はメモリのみ(保存しない)。上限は各スタック50件
- 対象外の操作に`@undoable`を付けない: `start`・`stop_running`・`toggle_execution`・`cancel_running`・`edit_record`・`delete_record(s)`・`recover_interrupted`・`stop_on_shutdown`・`keep_alive`
- `toggle_done`・`toggle_skipped`・`delete_category`は他のメソッドへ委譲するため、デコレータを付けない
- キーは`Cmd/Ctrl+Z`(Undo)、`Shift+Cmd/Ctrl+Z`または`Ctrl+Y`(Redo)。メイン画面と編集一覧で有効。ダイアログ表示中は無効だが、カテゴリ一覧の表示中は有効
- 通知文言: `元に戻しました: 〇〇`・`やり直しました: 〇〇`・警告`元に戻す操作がありません`・`やり直す操作がありません`
- コミットメッセージの末尾に`Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`を付ける
- このプロジェクトはコミット前にユーザーへ確認を取る決まり。各タスク末尾の「Commit」は、実行方式を選んだユーザーの承認の範囲で行う(承認が無ければ確認を取る)

## Review Focus

- 追加したアイテムを実行中に、追加を取り消す → 実行中の記録は停止して残る(Task 2)
- 名前を変更して取り消す → 既存の記録の名前も元に戻り、作業ログで別名のタスクが並ばない(Task 2)
- 繰越の対象が無いなど、何も変わらなかった操作 → 履歴に積まない(Task 2)
- 履歴が空の状態でUndo/Redo → エラーにせず警告を出す(Task 4)
- ダイアログ(編集フォームなど)の表示中のキー → 取り消さない(Task 4)。入力欄にフォーカスがある間はブラウザ標準の文字入力のUndoに任せる(`ui.keyboard`が入力欄のキーを無視する。手動確認)
- 取り消しで消えたアイテムが選択中だった → 選択を外し、次の操作で`KeyError`にならない(Task 3)

```python
from __future__ import annotations

from collections import deque
from dataclasses import dataclass

from todoapp.domain.models import Category, LinkTemplate, TodoItem

MAX_HISTORY = 50


@dataclass(frozen=True)
class Snapshot:
    """Undo/Redoで復元する状態。実行記録の本体は含めない(取り消しで、その後の計測時間が消えないようにするため)。"""

    items: list[TodoItem]
    categories: list[Category]
    link_templates: list[LinkTemplate]
    record_names: dict[str, str]  # 記録id → アイテム名。名前変更で揃えた記録の名前を戻すために持つ


class UndoHistory:
    def __init__(self, limit: int = MAX_HISTORY) -> None:
        self._undo: deque[tuple[str, Snapshot]] = deque(maxlen=limit)
        self._redo: deque[tuple[str, Snapshot]] = deque(maxlen=limit)

    def push(self, label: str, before: Snapshot) -> None:
        self._undo.append((label, before))
        self._redo.clear()

    def undo(self, current: Snapshot) -> tuple[str, Snapshot] | None:
        return self._swap(self._undo, self._redo, current)

    def redo(self, current: Snapshot) -> tuple[str, Snapshot] | None:
        return self._swap(self._redo, self._undo, current)

    @staticmethod
    def _swap(
        source: deque[tuple[str, Snapshot]], target: deque[tuple[str, Snapshot]], current: Snapshot
    ) -> tuple[str, Snapshot] | None:
        if not source:
            return None
        label, snapshot = source.pop()
        target.append((label, current))
        return label, snapshot
```

```python
def undoable[**P, R](
    label: str,
) -> Callable[[Callable[Concatenate[TodoService, P], R]], Callable[Concatenate[TodoService, P], R]]:
    """編集系のメソッドをUndoの対象にする。呼び出しの前後で状態が変わった場合だけ、履歴へ積む。

    メソッド同士が呼び合う場合(例: `delete_category`→`delete_categories`)は、一番外側の呼び出しだけを1操作として扱う。
    """

    def decorator(method: Callable[Concatenate[TodoService, P], R]) -> Callable[Concatenate[TodoService, P], R]:
        @functools.wraps(method)
        def wrapper(self: TodoService, *args: P.args, **kwargs: P.kwargs) -> R:
            if self._undo_depth > 0:
                return method(self, *args, **kwargs)
            before = self._snapshot()
            self._undo_depth += 1
            try:
                result = method(self, *args, **kwargs)
            finally:
                self._undo_depth -= 1
            if self._snapshot() != before:
                self._history.push(label, before)
            return result

        return wrapper

    return decorator
```

```python
    def _snapshot(self) -> Snapshot:
        return Snapshot(
            items=copy.deepcopy(self._data.items),
            categories=copy.deepcopy(self._data.categories),
            link_templates=copy.deepcopy(self._data.link_templates),
            record_names={record.id: record.item_name for record in self._data.records},
        )

    def _restore(self, snapshot: Snapshot) -> None:
        # 履歴側のスナップショットを後から書き換えないよう、コピーを戻す
        self._data.items = copy.deepcopy(snapshot.items)
        self._data.categories = copy.deepcopy(snapshot.categories)
        self._data.link_templates = copy.deepcopy(snapshot.link_templates)
        for record in self._data.records:
            name = snapshot.record_names.get(record.id)
            if name is not None:
                record.item_name = name
        running = self.running_record()
        if running is not None and all(item.id != running.item_id for item in self._data.items):
            self.stop_running()  # 実行中のアイテムが無くなった場合は、削除時と同じく記録を残して停止する
        else:
            self._save()

    def undo(self) -> str | None:
        """直前の編集操作を取り消し、その操作名を返す。履歴が空なら`None`。"""
        entry = self._history.undo(self._snapshot())
        if entry is None:
            return None
        label, snapshot = entry
        self._restore(snapshot)
        return label

    def redo(self) -> str | None:
        """取り消した操作をやり直し、その操作名を返す。やり直す操作が無ければ`None`。"""
        entry = self._history.redo(self._snapshot())
        if entry is None:
            return None
        label, snapshot = entry
        self._restore(snapshot)
        return label
```

    def prune_selection(self, item_ids: set[str], category_ids: set[str]) -> None:
        """Undo/Redoで無くなったアイテム・カテゴリを、選択から外す。"""

        self.selected_item_ids &= item_ids

            self.selected_category_id = None
        self.selected_category_ids &= category_ids
